# Code of Conduct

When you contribute to tokenstretch, respect the privacy of the people who use it.

tokenstretch is built to run entirely on the user's own machine. It is not designed to collect personal information, tracking data, IP addresses, usage analytics, prompts, files, or credentials, and it never sends anything off the machine. Contributions that add any of that, directly or through a dependency, will not be accepted.

Be respectful to everyone in issues and pull requests. To report a problem, email james@cas-tx.com.
