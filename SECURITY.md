# Security policy

tokenstretch runs locally and promises no telemetry, no network calls except pinned installs the user confirms, and never opening credential files. If you find a way it breaks any of those promises, or any other security issue, please tell us privately.

## Reporting a vulnerability

- **Please don't open a public issue.** Use GitHub's private vulnerability reporting ("Security" tab → "Report a vulnerability") on this repository.
- Include the version (`tokenstretch --version`), your OS, steps to reproduce, and what you expected.
- Never include real API keys, tokens, or credential files. Redact them.

We'll acknowledge your report as soon as we can, work on a fix, and credit you in the changelog if you'd like.

There is **no bug bounty**. This is a free, volunteer-run project.

## Supported versions

Only the latest release gets security fixes.
